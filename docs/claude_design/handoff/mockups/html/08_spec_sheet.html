部品と実装方法

部品tkinter / ttkメモ
強調ボタンttk.Button(style="Accent.TButton")各画面 1 つだけ：読み込み／Excelに出力／フォルダを開く
タブttk.Notebook ＋ tab(i, text=…)件数は文字で「出力する項目 9/12」。赤いバッジにしたい場合は PNG を image＋compound="right"
折りたたみttk.Button(style="Toolbutton") ＋ frame.grid_remove()閉じているときは 1 行の要約（間隔 1000 / 200 ms …）を表示。開閉状態は設定に保存
読み込み結果タイルtk.Frame(bg=tile, highlightthickness=1, highlightbackground=border)角丸は省略可（必要なら 9-slice PNG）
状態の帯（成功・警告・エラー）tk.Frame(bg=…) ＋ tk.Label(bg=…, fg=…)アイコンは ✓ ⚠ の記号文字、または 16px PNG
ドロップ枠（画面1）tk.Canvas ＋ create_rectangle(dash=(6, 4), outline="#8FB3DC")背景 #F2F7FC、高さ 220。ドロップ先として登録。ドラッグ中は枠を accent 実線に
項目の表ttk.Frame の grid（見出しはスクロール領域の外）グループ見出し「UART」「ロガー GL240」に採用数を表示
エラー／警告の行の色行ごとに tk.Frame(bg=…)、ttk 部品は Err.TLabel 等のスタイル入力欄は widget.state(["invalid"]) で赤下線
色見本tk.Button(bg=色, relief="flat", highlightthickness=1)44×24。押すとパレットの Toplevel(overrideredirect) を真下に
グラフ設定ttk.LabelFrame 相当の枠 ＋ ttk.Combobox(state="readonly")1 グラフ = 3 行（横軸／第1軸×2／第2軸×2）。幅 780 でも右端が切れない
エラー一覧の見出しttk.Label(cursor="hand2") ＋ bind("<Button-1>", …)notebook.select → スクロールして表示 → widget.focus_set()
スクロールCanvas ＋ Frame（サイドバーと表で別々）ホイールはカーソルの下の領域だけ動かす
ダークテーマsv_ttk.set_theme("dark") ＋ 上の色表の dark 列tk.Frame / tk.Label など sv-ttk が塗らない部品だけ手動で色を切替
