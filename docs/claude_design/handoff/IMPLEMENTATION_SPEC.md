# LogMerger GUI 改修 実装仕様

- 対象：ロガーCSV・UART CSV 統合ツール（exe 名 LogMerger）の GUI
- 実装：Python tkinter / ttk ＋ sv-ttk（Sun Valley）。ライト既定、ダーク対応
- 寸法：96dpi（表示倍率 100%）時の px。フォントは tkinter の負の値（ピクセル指定）
- 定数：`design_tokens.py`（本書の色名・寸法名はそこのキー）
- 見本：`mockups/*.png`（番号は README の表を参照）

---

## 0. 変えないもの（最優先）

- 機能：入力項目・操作の種類、各入力値の意味、エラーを出す条件、自動再計算（0.25 秒後）
- 画面の流れ：画面1 →［読み込み］→ 画面2 →［Excelに出力］→ 出力中 → 完了。［戻る］で画面1
- 画面1と画面2は同じウィンドウ内で切り替え。別ウィンドウは補助画面（欠落の詳細、カラーパレット、出力中、完了）だけ
- 設定の保存・前回値の自動入力
- Windows 標準のメッセージボックス（上書き確認、行数警告、読み込みエラー、保存失敗など）はそのまま
- エラーメッセージの**内容**。表示場所と前置き（場所の表示）だけ変える

  - 画面1 右端：「設定は前回の値を引き継ぎます」（caption）
  - 画面2 右端：読み込んだ 2 ファイルの名前「log40.csv ＋ 260924-090155.CSV」（caption）
- フッター（固定）：左右 24、ボタン高さ 32、ボタン間 8

## 2. 画面1 ファイル選択（mockups/01）

2. **ファイル欄 2 行**（行間 12）。grid 列：`[状態アイコン 28 | 見出し 132 | 入力欄 可変 | ［参照…］88]`、列間 12

   - 見出し：1 行目「UART CSV」/「ロガー CSV」（body_bold）、2 行目 補足「マイコンからの受信データ」/「GRAPHTEC GL240」（caption）

3. 補足（caption、左 40 字下げ）：「欄の上にドロップするとその欄に、枠内の他の場所なら中身で自動判別して入ります。」
4. **フッター**：右寄せで 補足「2つとも入力すると読み込めます」（caption）＋［読み込み →］（Accent、幅 148）
   - 2つ揃うまで無効（現行どおり）。揃ったら補足は非表示でよい
   - 形式エラー時はメッセージを出して画面1にとどまる（現行どおり）

表パネル内側 16、ブロック間 12。1 グラフ = 1 ブロック（枠 1px `border`、内側 12/16、角丸は任意）。

```

横軸          [time(ms)        ▾]
第1軸（左） 2つまで  [電圧(mV)   ▾]  [なし        ▾]
```

- grid 列 `[見出し 150 | 可変 | 可変]`、列間 12、行間 8。「2つまで」は caption
- プルダウンは `ttk.Combobox(state="readonly")`、高さ 30。選択肢・「なし」の扱いは現行どおり
- 最後に［＋ グラフを追加］（通常ボタン、「＋」は accent 色）
- ブロックが多いときはパネル内で縦スクロール
- 同じ項目の重複・第1軸未選択などのエラー時は、該当プルダウンを invalid にし、ブロック見出し行の右（削除の左）に理由（error, caption）

### 3.7 フッター（画面2）

- 左：［初期値に戻す］、その右（間 16）に**状態表示**（13px、アイコン付き）
  - エラー・警告なし：「✓ エラーはありません」（success）
  - 警告のみ：「⚠ 警告 N件（出力はできます）」（warning）。［Excelに出力］は有効
- 右：［戻る］（幅 96）［Excelに出力］（Accent、幅 148）。エラーがある間は［Excelに出力］無効（現行どおり）
- **エラーがあるとき**（mockups/04）：ボタン行の上にエラー一覧パネルを出す
  - パネル：bg `error_row`、上罫線 `error_border`、内側 上 10・下 8・左右 24。その下のボタン行は高さ 56
  - 見出し行（22）：「⚠ **N件のエラーを直すと出力できます**」（error, status）＋「赤い見出しをクリックすると該当の欄へ移動します」（caption）
  - 一覧：**2 列 × 最大 3 行**、列間 24、行の高さ 24。発生順に左列を上から、次に右列（列優先）。7 件目以降は最後に「…ほか N 件」
  - 各行：`[場所チップ] メッセージ`。場所チップは小さなボタン風ラベル（白地、枠 1px `error_chip_border`、文字 error 12px 太字、内側 1/8、cursor="hand2"）
  - 場所の書き方：`間隔・オフセット`／`項目 › <元の列名>`／`グラフ <No>`／`出力先`
  - チップのクリック：①該当タブを選ぶ（必要なら間隔セクションを開く）②対象ウィジェットが見えるまでスクロール ③`focus_set()`

## 4. エラー・警告の見せ方（まとめ）

同じ 1 件のエラーを 3 か所で同じ語でつなぐ。

| 場所 | 表示 |
|---|---|
| 入力欄・プルダウン | sv-ttk の invalid（赤下線） |
| 行・セクション・タブ | 行背景 `error_row`＋状態列の短い理由／間隔セクション見出し右「⚠ 1件」／タブ名「⚠ エラー N」 |
| フッター一覧 | `[場所] メッセージ`、クリックで移動 |

色の使い分け：成功＝`success`、注意（出力はできる）＝`warning`、エラー（出力できない）＝`error`。文字色だけでなく必ず ⚠／✓ 記号を添える。

## 6. ダークテーマ（mockups/06）

- `sv_ttk.set_theme("dark")` ＋ `design_tokens.DARK`
- sv-ttk が塗らない部品（tk.Frame / tk.Label / tk.Canvas / tk.Button の色見本など）は、テーマ切替時に色を再適用する関数を 1 か所に用意する
- 強調ボタンの文字は黒（`on_accent`）
- 切替の UI は今回は必須ではない（設定ファイルや OS 設定に従う方式で可。「11. 未確定事項」参照）

## 7. 部品と実装方法

| 部品 | tkinter / ttk | メモ |
|---|---|---|
| 強調ボタン | `ttk.Button(style="Accent.TButton")` | 各画面 1 つだけ：読み込み／Excelに出力／フォルダを開く |
| 通常ボタン | `ttk.Button` | 高さ 32、最小幅 96 |
| 小ボタン | 独自スタイル `Small.TButton`（padding を詰める） | 詳細…／削除（高さ 28） |
| タブ | `ttk.Notebook` | 件数は `tab(i, text=...)` で更新 |
| 折りたたみ | `ttk.Button(style="Toolbutton")` ＋ `frame.grid_remove()` / `grid()` | 開閉状態は設定に保存 |
| 読み込み結果タイル | `tk.Frame(bg=tile, highlightthickness=1, highlightbackground=border)` | 角丸は省略可 |
| 状態の帯 | `tk.Frame(bg=…)` ＋ `tk.Label(bg=…, fg=…)` | ⚠ ✓ は記号文字で可（または 16px PNG） |
| ドロップ枠 | `tk.Canvas` ＋ `create_rectangle(dash=(6, 4))` ＋ `create_text` | tkinterdnd2 等のドロップ先に登録 |
| 項目の表 | 見出し用 Frame ＋ スクロール用 Canvas 内の Frame、どちらも同じ `columnconfigure(minsize=…)` | 列幅をそろえる |
| 行の背景色 | 行ごとに `tk.Frame(bg=…)`。ttk 部品は `Err.TCheckbutton` / `Err.TLabel` 等の背景付きスタイル | 通常／警告／エラーの 3 種 |
| 入力欄のエラー | `widget.state(["invalid"])` / `state(["!invalid"])` | sv-ttk の赤下線 |
| 色見本 | `tk.Button(bg=色, activebackground=色, relief="flat", highlightthickness=1)` | 44×24 |
| エラー一覧の場所チップ | `tk.Label(cursor="hand2")` ＋ `bind("<Button-1>", …)` | Tab キーでも移動できるよう `takefocus` と `<Return>` も |
| スクロール領域 | Canvas ＋ 内側 Frame ＋ ttk.Scrollbar（サイドバー／項目表／グラフで別々） | ホイールはカーソル下の領域だけ動かす |
| プログレスバー | `ttk.Progressbar(mode="indeterminate")` | |

## 8. リサイズ・DPI

- 幅が広がったら項目表のラベル列だけ伸ばす（最大 320）。他の列・サイドバー幅は固定
- 高さが足りない場合はサイドバー・表パネルがそれぞれスクロール。ヘッダー・フッター・タブは常に表示
- 1280×720 のノート PC（表示倍率 100%）で横スクロールが出ないこと
- 表示倍率 125%/150% では `design_tokens.scale()` で寸法を換算（フォントは負の px 指定なので tk の scaling に合わせて調整）
