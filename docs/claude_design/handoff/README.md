# LogMerger GUI 改修 — Claude Code 引き継ぎ資料

ロガーCSV・UART CSV 統合ツール（LogMerger）の GUI を、デザイン案どおりに
**tkinter / ttk ＋ sv-ttk** で作り直すための資料一式です。

## Claude Code への依頼（このままプロンプトとして使えます）

> このフォルダ（`handoff/`）の資料をもとに、LogMerger の GUI を改修してください。
>
> 1. まず `IMPLEMENTATION_SPEC.md` を最後まで読み、`mockups/*.png` を全部見てください。
>    現在の画面は `reference/current/screenshots/`、現在の部品一覧は `reference/current/ui_structure.json` です。
> 2. 既存コードの GUI 部分を調べ、**機能・入力値の意味・エラー条件・画面1→画面2 の流れは変えずに**、
>    見た目と配置だけを仕様どおりに組み替えてください（仕様書「0. 変えないもの」）。
> 3. 色・フォント・寸法は `design_tokens.py` を取り込んで使い、値を直書きしないでください。
> 4. 仕様書「9. 実装の順番」の順に進め、各段階で動作確認してください。
> 5. 最後に「10. 受け入れチェックリスト」を 1 つずつ確認し、結果を報告してください。
> 6. 仕様で決めきれない点（「11. 未確定事項」）は、勝手に決めずに質問してください。

## フォルダ構成

| パス | 内容 |
|---|---|
| `IMPLEMENTATION_SPEC.md` | 実装仕様（本体）。画面ごとの部品配置・寸法・色・状態・実装方法 |
| `design_tokens.py` | 色（ライト／ダーク）・フォント・寸法の定数。そのまま import 可 |
| `mockups/01〜08_*.png` | デザイン案の画像（1120×720 基準、100% 表示） |
| `mockups/html/*.html` | 同じデザイン案の静的 HTML（ブラウザで開くと寸法を確認できる） |
| `reference/current/` | 改修前の資料（依頼書・現在の画面・部品一覧） |
